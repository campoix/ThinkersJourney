## 📜 Descrição

Thinkers Journey é um jogo de simulação de carreira corporativa de um estudante de Ensino superior que deseja iniciar sua trajetória profissional em IA, o projeto traz conteúdos abordados no curso IBM SkillsBuils, agentes de IA, Machine Learning e ética no uso de IA como exemplos. O jogo surge de uma dor enfrentada pela empresa e sua plataforma de cursos que não conseguia manter o engajamento de seus alunos. Nele, o jogador realiza minigames (atividades) que o levam a ascender, andar por andar, aos cargos da empresa fictícia Thinkers. Por meio de uma parceria entre Inteli (Instituto de Tecnologia e Liderança) e IBM (International Business Machines Corporation), o Thinkers Journey propõe uma visão diferenciada às formas mais tradicionais de educação, abordando assuntos de IA com mecânicas interativas dentro de cenários de um jogo empresarial, as quais visam a incrementar o engajamento e o aprendizado dos usuários que desejam aprender sobre o tema.

## 📁 Estrutura de pastas

Dentre os arquivos e pastas presentes na raiz do projeto, definem-se:

- <b>documents</b>: Aqui estão todos os documentos do projeto, como o Game Development Document (GDD) bem como documentos complementares, na pasta "other" e elementos visuais utilizados nos documentos, na pasta assets que se localiza dentro da documents.

  - <b>assets</b>: Aqui estão os arquivos relacionados a elementos não-estruturados deste repositório, como imagens. Nesse caso, aqueles elementos utilizados nos documentos.
  
  - <b>gdd.md</b>: O GDD ou Game Development Document é o arquivo principal da documentação do projeto, nele estão presentes referências, descrições do processo de desenvolvimento do projeto, imagens do jogo e testes realizados.

- <b>public</b>: Nessa pasta estão contidos todos os arquivos referentes ao jogo desenvolvido no projeto.

  - <b>assets</b>: Aqui estão os arquivos relacionados a elementos não-estruturados deste repositório, como imagens e vídeos. Dentro da public, os assets são referentes àqueles do jogo.

  - <b>src</b>: Contém o arquivo .js do jogo.

    - <b>script.js</b>: Todo o código criado para o desenvolvimento do projeto do jogo.

  - <b>index.html</b>: Todo o formato html do jogo.

  - <b>style.css</b>: Todo a estilização via css do jogo.

- <b>.git-ci.yml</b>: Código necessário para a publicação do link do jogo.

- <b>README.md</b>: Arquivo que serve como guia e explicação geral sobre o projeto e o jogo (o mesmo que você está lendo agora).

- <b>index.html</b>: Todo o formato html do jogo.



## 🔧 Como executar o código

O usuário que deseja acessar o jogo pode o fazer pelo link. Para executar o código, a instalação da pasta zip no repositório é necessária. Após a extração dos arquivos, o usuário deve abrir a pasta no Visual Studio Code ou aplicativo semelhante, instalar uma extensão como o "Live Server" e abrir o arquivo html que se encontra dentro da pasta public com a extensão, seguindo esses passos, o jogo irá abrir por execução do código em um servidor local.
